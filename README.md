# SEIKEI v1.0.1

高校の「公共」「政治・経済」の出来事を、西暦と前後関係から覚える静的Webアプリです。アカウントやバックエンドは不要です。設定、直近200回答、復習対象はブラウザの `localStorage` に保存します。

出題順もモードごとに端末内へ保存します。一度表示した出来事は、現在の学習範囲を一巡するまで再登場しません。ホームに戻ったりページを再読込したりしても続きから出題します。復習は通常学習とは別の一巡です。範囲を変えると新しい一巡を始めます。年代整序は最初の問題を4件とし、全件を重複なく出すため最後だけ2〜3件になることがあります。年の偏りで重複なしの整序を作れない範囲では理由を表示します。履歴削除は一巡の進み具合も消します。

## 起動

```sh
npm run dev
```

`npm test` で出題・判定・絞り込み・保存を検証します。公開時は `index.html`、`src/`、`data/reviewed.json`、`assets/`、`manifest.webmanifest` を静的ホストに配置してください。外部パッケージは不要です。

v1.0.1では、年号入力時に数字キーと回答ボタンを作り直さずに表示だけを更新し、タッチ操作とキーボードのフォーカスを維持します。正解時は短いチェックマークの演出を表示します。端末の「視差効果を減らす」設定ではアニメーションを停止します。

タッチ操作の回帰テストは、開発用のPlaywrightとWebKitをインストールした環境で、`npm run test:touch` を実行してください。テスト用サーバーを自動起動し、iPhone・iPad相当の画面サイズで、連続入力・削除・正解・不正解・履歴の保存・外付けキーボードのEnterを検証します。実機のiOS検証とは区別しています。

アプリアイコンは `assets/seikei-icon.png` です。ホームのロゴ、ブラウザのfavicon、iPhoneのホーム画面用アイコンに共通で使います。紺から青の背景に、3つの点を通る白いS字の年表線を描いた画像で、built-in imagegenで生成しました。

## ローカル開発ダッシュボード

`npm run dev` のあと、[http://127.0.0.1:4173/dashboard/](http://127.0.0.1:4173/dashboard/) を開いてください。アプリ本体は [http://127.0.0.1:4173/](http://127.0.0.1:4173/) です。サーバーは `127.0.0.1` のみで待ち受けるため、このパソコンからだけアクセスできます。

- タスクの状態とブロック理由を編集できます。
- 開発側は質問を追加でき、ユーザーは画面から回答できます。回答は5秒ごとの更新と `GET /api/dashboard` で取得できます。
- アプリのプレビュー、`artifacts/` の画像、レビューの記録と対応状態を確認できます。
- カード件数・カテゴリ数・保留候補数・成果物の更新日時は実ファイルから読みます。テスト結果は「テスト実行」ボタンから更新します。費用やAPI使用量など、取得できない値は表示しません。
- 入力内容とテスト結果は `dashboard-state.json` に保存されます。外部サービスへの送信やCodexとの自動連携はありません。

開発エージェントは同じパソコンからJSON APIでタスクや質問を更新できます。例えば質問を追加する場合は、PowerShellで次を実行します。

```powershell
$body = @{ question = '次の画面はどちらを優先しますか？'; urgency = 'normal'; defaultAction = '既存画面の改善を続ける' } | ConvertTo-Json
Invoke-RestMethod -Uri 'http://127.0.0.1:4173/api/dashboard/questions' -Method Post -ContentType 'application/json' -Body $body
```

主なAPIは `GET /api/dashboard`、`POST /api/dashboard/tasks`、`PATCH /api/dashboard/tasks/{id}`、`POST /api/dashboard/questions`、`POST /api/dashboard/questions/{id}/answer`、`POST /api/dashboard/reviews`、`PATCH /api/dashboard/reviews/{id}`、`POST /api/dashboard/tests` です。書き込み時はJSONを送ってください。

## 学習レベル

4段階です。`4=最優先`（最初に覚える）、`3=必須`（基本の年号）、`2=標準`（範囲を広げる）、`1=補強`（難しめの事項）。初期設定は最優先と必須の49件です。以前の初期設定で使っていた端末では、保存済みの回答履歴を残したまま新しい初期設定に移行します。個別に変更した学習範囲は可能な限り引き継ぎます。

## データ監査

- 入力候補: `civics_events_candidates_v1.json` の291件（ユーザー添付）。候補は公開用の検証済みデータではありません。
- 採用: `data/reviewed.json` の97件。うち94件が添付候補由来、3件が今回の参考リンク由来です。各カードの `sourceUrl` は、名称・年・年の意味を確認した公的機関などのページです。問題画面から開けます。
- 追加: 指定された[Quizlet](https://quizlet.com/jp/868871709/政治経済覚えるべき年号-flash-cards/)、[武田塾](https://www.takeda.tv/sugamo/blog/post-211188/)、[note](https://note.com/study12345/n/n384d878c2f2c)、[Ankilot](https://ankilot.com/view/?id=5NkJia2IDj)を候補の手がかりにし、38件を個別に照合して追加しました。4サイト自体を各行の証拠にはしていません。追加項目は監査ファイルの `addedFromLinkedReferences` に記録しています。Quizletはページの直接取得が制限され、一部の検索結果だけを参考にしました。
- 保留: 添付291候補のうち197件。187件は個別資料による照合未完、10件は採用済みカードへ統合した別表現です。リンク先にある他の未照合項目も出題されません。例は監査ファイルの `linkedReferenceDeferred` に記録しています。
- 修正: 「アメリカ合衆国憲法の制定」は1787年の事実に合わせ「署名」に変更しました。参考リンクの「沖縄返還1971年」は復帰を1972年、「帝国憲法施行1889年」は1890年、「日本の子どもの権利条約批准1999年」は1994年に修正して採用しました。「ユーロ流通開始」は電子決済の1999年と現金の2002年を区別しました。重複する事象は1枚にまとめ、関連カテゴリを追加しています。内容は監査ファイルの `yearOrTitleCorrections` と `corrections` に記録しています。
- 学習レベルは4段階に再分類しました。変更した項目ごとの旧値・新値は監査ファイルの `levelChanges` に記録しています。これは学習順序についての編集判断で、史実の検証結果とは区別しています。
- 年月日はカードには保存していません。同じ年でも「公布」「施行」などは別カードとし、年代整序では同じ年を同時に選びません。

`tools/build-data.ps1` は添付ファイルがダウンロードフォルダにある環境で `pwsh -File tools/build-data.ps1` により監査済みデータを再生成するためのスクリプトです。選定リストと行ごとの資料URLはスクリプトに明記しています。採用範囲を増やす場合は、各候補を個別に照合してからリストに追加してください。

## 制約

- 291候補のうち187件は未照合のため、現時点では学習対象外です。指定された4サイトの全項目も網羅していません。14カテゴリの選択肢はすべて維持していますが、カテゴリごとの収録数には差があります。
- ブラウザの保存領域を消すと履歴は消えます。端末間同期はありません。
- フォントが取得できない環境でもシステムフォントで表示します。
